# Kalkulator TENDER — Installer

Aplikasi Windows untuk menyusun RAB, Analisa Harga Satuan (AHSP), Time Schedule dan Kurva S — **Berliaan Group**.

## Unduh

Buka halaman **[Rilis terbaru](https://github.com/Berliaan/kalkulator-tender-rilis/releases/latest)**, lalu unduh:

- `Setup-Kalkulator-TENDER-<versi>.exe` — installer aplikasi (±110 MB)
- `Tutorial-Lengkap-Kalkulator-TENDER.pdf` — panduan langkah demi langkah
- `Panduan-Pengguna-Kalkulator-TENDER.pdf` — ringkasan pemakaian
- `Contoh.Proyek.-.Pos.Jaga.3x4.m.rab` — contoh proyek siap buka

## Cara memasang

1. Jalankan file `Setup-Kalkulator-TENDER-<versi>.exe`.
2. Bila muncul layar biru "Windows protected your PC", klik **More info → Run anyway**.
3. Ikuti langkahnya (Lanjut → Saya Setuju → Instal).
4. Buka aplikasi, klik **Masuk**, isi email + kode (kode coba gratis atau kode lisensi Mayar).

Kebutuhan: Windows 10/11 64-bit, ±350 MB ruang disk.
